SEC-02 · Destructive commands pass or depend only on manual confirmation

Tipo
medido (mf-2)
Impacto
Alto
Nivel de evidencia de la regla
documentación oficial
Resumen
Git commands that discard work or rewrite shared history pass without a prompt, because the allow rule for git covers them. The project mode also accepts edits without asking.
Recomendación
Add deny rules for the destructive git forms, ask rules for rm, and a PreToolUse hook on Bash that fails closed, then remove acceptEdits from the project settings.

Run each destructive command of the scan in a scratch copy of the project and record whether it runs, asks or is blocked.

SEC-05 · Security rules exist only as text

Tipo
criterio
Impacto
Medio, una opinión: un hallazgo de criterio no tiene una medición detrás
Nivel de evidencia de la regla
documentación oficial
Resumen
The subagent body forbids destructive commands in plain text. Its shell tools inherit the project's acceptEdits mode, so nothing asks before those commands run, and no setting enforces the sentence.
Recomendación
Put the forbidden forms in deny rules in the project settings, and keep the sentence only as an explanation for the reader.
Prueba en la función 2
Ask the subagent to run each forbidden form and record whether the call asks, runs or is blocked, with and without the sentence.
